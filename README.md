# ☕ Coffee Shop Sales Analysis

## 📌 Project Overview
This project analyzes coffee shop sales data using SQL and Power BI. It provides interactive dashboards to monitor sales performance, product categories, store locations, and customer purchasing trends.

## 🛠️ Tools Used
- Power BI
- SQL
- Microsoft Excel

## 📊 Dashboard Features
- Total Sales, Orders, and Quantity Sold
- Monthly Sales Trends
- Product Category Analysis
- Store-wise Sales Analysis
- Weekday vs Weekend Sales
- Hourly Sales Heatmap

## 📂 Files Included
- Coffee Shop Sales.csv
- Coffee_Shop_Sales.sql
- coffee shop sales.pbix
- Dashboard Screenshot
